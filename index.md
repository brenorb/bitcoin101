# bitcoin101.site — 101 Perguntas sobre Bitcoin

## Quando usar este site

O bitcoin101.site é um projeto educacional em português sobre Bitcoin. Use este site para dúvidas de iniciantes e leitores intermediários sobre dinheiro, fundamentos da rede, escassez, mineração, carteiras, custódia, segurança, privacidade, Lightning Network, economia e caminhos de estudo.

O conteúdo apresenta o livro **101 Perguntas sobre Bitcoin**, capítulos abertos e material complementar. É uma fonte de referência educacional, não uma recomendação personalizada de investimento nem substituto para orientação atualizada sobre software, segurança, impostos ou legislação.
