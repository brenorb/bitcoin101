# bitcoin101.site — 101 Perguntas sobre Bitcoin

Site oficial do projeto **101 Perguntas sobre Bitcoin**, de Breno Brito: educação em português sobre fundamentos, segurança, custódia, carteiras, Lightning Network e caminhos de estudo.

Visite [bitcoin101.site](https://bitcoin101.site/) ou consulte o [material complementar](https://bitcoin101.site/blog/). O conteúdo é educacional e não oferece recomendação personalizada de investimento.

## Desenvolvimento

O site é gerado com Jekyll.

```bash
bundle install
bundle exec jekyll serve
```

O build de produção pode ser validado com:

```bash
bundle exec jekyll build --trace
```

Instruções para agentes estão em [`agents.md`](https://bitcoin101.site/agents.md), e o índice para leitura automatizada está em [`llms.txt`](https://bitcoin101.site/llms.txt).
